# Node7 design direction

Audience: founders and growing businesses comparing website design partners.
Primary action: book a consultation. Secondary action: understand services, scope, and indicative pricing.

## Direction
A restrained editorial studio identity. The dominant reference is Build in Amsterdam's direct agency positioning and large-scale type; Instrument informs the work-to-services narrative. This site retains Node7's existing near-black and lime identity, but avoids repeating glass cards. Imagery is illustrative until approved client case studies are supplied.
The hero uses a generated editorial studio photograph with abstract layout studies and no readable mock website copy. The responsive study is a generated device composition with abstract, text-free screens. The process study shows physical wireframe sketches. All three are WebP assets.

## Tokens
- Background: #11120f; surface: #1b1d19; foreground: #f1f0e8.
- Muted text: #a9aba2; border: #3a3d34; action/accent: #c6f36a.
- Typography: local Arial/Helvetica fallback stack with tight display tracking and clear text hierarchy. Display uses responsive clamp sizing; body stays near 16–18px. This avoids a build-time remote font request.
- Spacing: 18–32px page gutters; 75–160px section rhythm; 16–32px component gaps.
- Shape: square editorial sections and buttons; 0.75rem radius remains available for utility components.
- Elevation: flat surfaces and rules rather than shadows.
- Motion: subtle hover movement/scale only where it signals interaction. Reduced-motion media query disables transitions and smooth scrolling.
- States: visible focus outline, dark-on-lime primary action, hover contrast, accessible expandable FAQ rows.
